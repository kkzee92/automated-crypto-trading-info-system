# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a Vulnerability

Please open a private security advisory or contact the maintainer directly. Do not open public issues for vulnerabilities.

## Key Rules

- Never commit secrets.
- API keys must have no withdrawal permissions.
- All strategy changes that could influence capital allocation require human review.
